# Productivity Tracker

A **Productivity Tracker** app designed to help users manage their time effectively. The app features a **Pomodoro timer**, focus session tracking, daily/weekly metrics, and streak-based gamification, all wrapped in a clean and user-friendly interface.

---

## Features

- **Pomodoro Timer**: A 25-minute focus session with 5-minute breaks.
- **Focus Metrics**: Track daily and weekly focus times with visual analytics.
- **Gamification**: Earn streaks and badges for consistent study or work habits.
- **User Authentication**: Secure login and registration using JWT.


---

## Tech Stack

### Frontend
- **Next.js**: React-based framework for server-side rendering and API routes.
- **@tanstack/react-query**: Manage server state efficiently.
- **Redux**: Centralized state management.
- **Tailwind CSS**: Utility-first CSS framework for styling.

### Backend
- **MongoDB**: NoSQL database for storing user and session data.
- **Mongoose**: Elegant MongoDB object modeling for Node.js.
- **JWT**: Secure token-based authentication.
- **Next.js API Routes**: Built-in backend routes for API endpoints.
